Stappen om code naar pi te krijgen
1) open powershell
2) ssh eric@raspberrypi.local
--wachtwoord ingeven
3)cd ~/ai-crypto-pulse-bot/raspberry-pi
4) (check current) git log --oneline -5
5) git pull
6) (check new) git log --oneline -5 (moet een nieuwe main hebben)
7) (Restart service) sudo systemctl restart cryptopulse-runtime.service
8) (check na restart) sudo systemctl status cryptopulse-runtime.service
